# 德州扑克微信小游戏

一个纯娱乐的德州扑克微信小游戏，支持好友房联机和AI机器人对战。

## 快速开始

### 在微信开发者工具中运行

1. 打开微信开发者工具
2. 选择「小游戏」项目
3. 导入 `texas-holdem` 目录
4. 填入你的小游戏 AppID（或使用测试号）
5. 运行预览

### 运行测试

```bash
node test/test_engine.js
```

### 启动联机服务端（好友房）

```bash
cd server
npm install ws
node server.js
```

## 功能清单

### 核心玩法
- ✅ 好友房（微信好友邀请、房间号加入、密码、人数2~9、初始筹码、盲注设置、AI补位）
- ✅ AI机器人对战（1~8个AI、四种难度：新手/普通/高手/职业）
- ✅ 100%符合国际德州扑克规则（发牌、盲注、Button、翻牌、转牌、河牌、摊牌、Side Pot、All in、Raise、Fold、Check、Call、Bet）

### AI引擎
- ✅ 绝不作弊，不读取任何玩家底牌
- ✅ 基于：自己手牌、公共牌、玩家下注、底池赔率、位置、历史行为
- ✅ 蒙特卡洛模拟估算胜率
- ✅ 四种难度差异化策略（新手随机性大、职业AI有范围平衡和诈唬）

### 经济系统
- ✅ 金币（游戏币，不涉及人民币）
- ✅ 信用等级（300-850分）
- ✅ 游戏内贷款（额度、利息、每日还款、逾期降信用、信用恢复）

### 玩家数据
- ✅ ID、昵称、头像、金币、信用等级、贷款余额
- ✅ 历史战绩、胜率、最大盈利、最大连胜

### 界面
- ✅ 大厅：创建房间 / 加入房间 / AI快速开始
- ✅ 游戏桌面：椭圆形牌桌、玩家座位、公共牌、底池、筹码、操作按钮
- ✅ 创建房间：人数/筹码/盲注/AI数量/AI难度设置

### 不做的功能（第一版）
- ❌ 战令、VIP、世界聊天、公会、排行榜、邮件、商城、活动

## AI 决策原理

AI 只使用公开信息进行决策，绝不读取其他玩家的底牌：

1. **手牌强度**：翻牌前使用查表法，翻牌后使用蒙特卡洛模拟（200-300次迭代）
2. **底池赔率**：`callAmount / (pot + callAmount)`，胜率 > 赔率才跟注
3. **位置意识**：Button位置加成最大，盲注位置减成
4. **对手分析**：根据对手历史行为估算激进度
5. **听牌评估**：同花听牌、顺子听牌的完成概率
6. **诈唬策略**：高手和职业AI会根据位置和对手进行半诈唬/纯诈唬

## 技术说明

- 渲染：纯 Canvas 2D，无第三方引擎依赖
- 通信：WebSocket（好友房联机）
- 存储：微信本地存储API
- 规则：100%符合国际德州扑克标准规则
